归一 Unyra v0.6.7 —— 专注模式取代番茄钟、日程表、两类记忆、随笔改为全量提交，以及一段式滚动渐隐和一处数据目录设置的关键修复。

## 专注模式：只有守卫，没有倒计时

- **番茄钟整体撤掉**：计时器、组数、「跑完才记一笔」全不在了，只剩守卫。
- **准入条件**：开一场专注必须先开一路监控（屏幕 / 摄像头），一路都不开时按钮直接禁用。
- **守卫每分钟看一眼**：分心提醒、离开即暂停、隐私画面立即熔断；暂停只标记不冻计时。
- **结束时留下专注报告**，记录按实际守住的时长算，不再要求「跑完一整组」。
- **老数据自动迁移**：状态文件的键从 `pomodoro` 改为 `focus`，读盘时把旧记录折成新的。agent 只读接口随之换成 `api.focus.status`。

## 日程表

- **用户级日程**：文档区「日程安排」页签按天查看、就地编辑、删除二次确认。
- **到点提醒**：持续响铃 + 顶栏渐变呼吸 + 提醒弹层（知道了 / 稍后 5·10·30 分钟 / 打开日程表）。多条同时到点只响最早那一条。
- **四档铃声**现场合成（风铃 / 钟声 / 提示音 / 柔和）并可调音量，设置新增「提醒」分页。
- **导师能排日程**：`api.schedule.*` 进沙箱名单，省略日期按今天算，时间已过则顺延到明天。

## 记忆：工作 / 长期两类

- **工作记忆**是目标级的，只在本目标的会话里可见，导师觉得是负担可以随手删；**长期记忆**跨目标共享（印象、作息、重要约定），删除必须二次确认。
- 新组 `api.memory.{list,get,create,update,delete}`，旧的 `mind.*` 整组退役。
- **记忆管理**一份实现两个入口（设置页、文档区页签）：两类分区、搜索、按类型 / 目标筛选、就地编辑、展开全文、清空某个目标的工作记忆。
- 删除学习目标时连带清掉它的工作记忆，长期记忆不动。

## 随笔：一次提交封存全部

- **提交改为全量快照**：每次提交封存当前全部随笔，并与上一次快照比对（新增 / 修改 / 删除 / 未变化），有变化才允许提交。
- **提交历史与详情改成目标级**，不再按某一条随笔切分——每条提交本来就包含所有随笔。
- **用标题标识随笔**：标题可改，缺省取创建当天日期；「笔记」页签只列当前目标的笔记。
- 窗口顶部改成随笔 / 笔记两个 Tab，二级页面状态关窗后恢复上次停留处。

## 阅读与对话

- **两端渐隐改用遮罩**：聊天列表与文档区滚到端点时自动收掉渐隐，静止在顶部 / 底部时第一行与最后一行不再被淡化；开了图片背景也不再需要把渐隐整个关掉。
- **思考过程**展开限高 22rem、框内滚动；人格 / 文档格式 / 技能库 / 提示词模块不再画分界条，并进那一轮的过程组，分界条只留给工作流指令。
- **自动贴底更稳**：Markdown、图片、工具卡是渲染之后才长高的，现在长高也跟着贴；内容变矮不会再被误判成「用户往上翻」。

## 修复

- **数据目录设置会丢（#143）**：`global.yaml` 改成原子写并保留上一份。此前更新时被杀进程、断电都会留下一个 0 字节或半截的文件，下一次启动就静默回落成默认存储位置，学习目标与 API key 看起来全没了——而且再保存任何设置都会把这个默认值写死。现在写一半被杀不会留下坏文件，主文件读不出来时还能退回上一份。
- **考试窗口跳题**只滚题目流，不再把整页一起滚上去、下面留一大片空白。
- **空白页签**图标换成一张空白的纸，未选中时轻微呼吸提醒，不再像「新建」按钮。

## 内部

- 沙箱 api 目录收敛成注册表的投影，worker 名单从注册表派生，应用数据路径加了一道闸门；提示词模块与 execute 指南跟着改成 api 组口径。
