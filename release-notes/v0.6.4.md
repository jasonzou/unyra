归一 Unyra v0.6.4 —— 沉浸式双模网页翻译（极速 / AI 深度）、模型非思考模式与零思维链优化、动态自定义扩展语言包，以及 Mermaid 矢量图表渲染尺寸自适应调优。

## 网页沉浸式双模翻译与划词翻译

- **双模翻译通道**：内置浏览器右键菜单新增「极速双语翻译（免费公用）」与「AI 深度双语翻译（当前配置模型）」，支持划词浮层卡片与整页双语对照。
- **极速并发独立派送**：免费公用通道采用多段独立派发高并发请求（20 路并发），哪个完成就立刻挂载哪个，无需等待全部完成或显示进度阻塞。
- **AI 深度翻译分块与限频**：AI 模型翻译采用动态打包合并策略，并对并发做限额控制，有效节省 Token 消耗与避免触发服务商频率限制。
- **持久化翻译缓存层**：基于 FNV-1a 确定性哈希与本地存储，相同网页或相同段落重复打开秒级命中缓存，实现零额外 Token 开销。
- **译文样式克隆与融入**：译文块克隆原 DOM 节点的标签名、排版与样式属性，列表、标题与段落紧随原文无缝对齐，支持快捷隐藏/显示双语对照与一键清除译文。
- **动态内容监听与增量翻译**：开启 MutationObserver 监听网页 DOM 变动，SPA 单页应用或无限滚动瀑布流加载新内容时自动增量翻译。
- **代理穿透与请求校验**：支持系统代理与环境变量代理分发（`undici.ProxyAgent`），保障海外直连 Google 翻译 RPC；严格过滤超额限制信息，并防止同文回写与错误状态锁定。

## 模型非思考模式与思维链抑制

- **支持 None 思考强度档位**：模型设置中的思考强度（Reasoning Effort）新增 `None`（非思考模式），用于关闭耗费大量 Token 与时延的思维链。
- **各大主流厂商非思考参数适配**：深入适配 DeepSeek (`thinking: { type: "disabled" }`)、SiliconFlow (`enable_thinking: false`)、Anthropic (`thinking` 关闭)、OpenAI (`reasoning_effort: "none"`) 等主流服务商的非思考模式规范。
- **翻译提示词抑制思维链**：双语翻译场景显式约束严禁输出思考过程与多余说明，显著缩短单次请求输出 Token 并加快渲染。

## 国际化自定义扩展语言包

- **支持扩展自定义语言包**：支持从应用 `locales/` 目录动态读取外部 JSON 语言包，键值自动覆盖现有界面词条，中英文内置保底回退。
- **语言包管理工具**：外观设置面板新增「打开语言包目录」、「新建空白语言包（一键生成 `template.json` 模板文件便于用户扩展填词）」以及即时刷新语言列表按钮。
- **翻译目标语言联动**：网页翻译目标语言自动跟随当前 UI 语言设置。

## Mermaid 渲染尺寸与排版自适应优化

- **修复强制拉伸导致的巨型方框**：解决小尺寸 Mermaid 图表（如 1~2 列流程图）被强制拉伸至 100% 容器宽度导致字体与节点过度放大的问题，严格保留并限制在固有自然尺寸（`min(100%, naturalWidth)`）并居中呈现。
- **收紧排版密度**：默认节点字号调为 13px，节点内边距由 15px 收紧为 10px，同层间距由 50px 调为 30px，层级垂直间隙由 50px 调为 35px，时序图字体同步调整，图表呈现更精致紧凑。
