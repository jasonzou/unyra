归一 Unyra v0.7.0 —— 重大版本发布：学习结构升级为「节点宇宙」无限画布、新建目标模式重构与轻量化、手机扫码局域网互联与手写答卷审卷判分、视频学习资源化与插件化体系，以及 Codex 风格流动能量滑块与空消息引导重构。

## 节点宇宙：无限画布与学习体系重构

- **结构页重构为节点宇宙**：告别单向线性的树状大纲，学习结构页全面升级为 2D 纯净无限画布（Node Graph），支持全类型知识实体（文档、大纲、笔记、试卷、超级文档、视频）在画布中自由拖拽摆放、建立层级连线与拓扑关联。
- **新建目标流程彻底解耦**：移除强制生成根文档、前置知识大纲与学习大纲的繁琐闭环。新建目标只需命名，即刻创建纯净的空白宇宙与独立的空 Agent 会话，用户可根据学习节奏自由规划与按需生成。
- **全新新手教学系统**：为节点宇宙重构新手教学流程，内置只在教学期间展示的专属假数据与步骤遮罩；教学结束后自动清空恢复，学习状态通过本地存储持久化记录，首次进入自动贴心引导。
- **空白页签高亮引导**：当资源管理器尚无任何学习目标时，空白页签的「新建目标」快捷入口自动触发柔和的印章色呼吸光晕与「推荐首选」徽标，贴心指引起步。

## 局域网互联与考试手写答卷判分

- **内置局域网互联服务（LAN Sync）**：无需公网服务器，电脑端内置轻量局域网服务；未建立连接时自动弹出二维码引导窗口，手机扫码建立连接后窗口自动静默关闭，并将暂存请求无缝发出。
- **手机拍照上传手写答卷**：在考试窗口中，支持随时通过手机扫码上传答题卡或草稿纸作答照片，无需纯打字输入；支持答卷 90° 原地旋转校正角度。
- **超级导师亲自审卷判分**：交卷后由 AI 导师直接审阅手写原卷，自动裁切答卷局部贴入对应试题，记录错题规律并动态修正概念掌握度。

## 视频学习：知识实体化与来源插件化

- **视频作为第一类知识节点**：视频节点可与教学文档连线绑定，视频学习页签保持常驻状态，自动持久化播放进度与选集。
- **视频来源全插件化**：应用本体与具体视频平台彻底解耦，平台适配器通过插件机制热插拔装卸。
- **定制化播放器体验**：支持外挂双语字幕与无背景实心硬描边自适应渲染、转录文字跟随视频精准定位、选集列表平滑悬浮窗，并可一键提取字幕生成视频总览文档。

## 思考档位调节器：Codex 风格流动能量胶囊

- **能量液管与平缓流动微粒**：告别生硬的分段选项卡，重做为微光圆角胶囊能量管，内置如零重力星尘般自主横向平缓流动的微粒流（Fluid Bubble Stream），纯白微宝石圆钮随档位平滑吸附。
- **随档位动态切换主题色**：
  - 无 (None)：沉静中性灰；
  - 低 (Low)：清爽薄荷绿；
  - 中 (Medium)：温暖琥珀金；
  - 高 (High)：深邃紫罗兰；
  - 最大 (Max)：经典印章红。
- **帧率无关的平缓物理流速**：基于真实时间增量（dt）计算粒子位移，在高刷电竞屏与标准显示屏上均保持绝对一致的从容流速。
- **极简居中无边框引导**：彻底移除导师对话区原先带边框圆角的空消息卡牌，改为雅致垂直居中的印章红灵动图标、欢迎标语以及 3 组一键填入的常用快捷提问引导。

## 修复与体验打磨

- **结构页签与资源管理器联动**：修复关闭空目标的结构页签后，点击资源管理器目标项无法重新打开结构页的缺陷。
- **顶栏页签组标题**：修复目标顶栏标签组名称偶发显示为空的问题。
- **试卷记录反查**：修复考试记录中手写原图与裁切贴图在重开应用时丢失及反查引用解析异常。
- **画布操作手感**：优化节点双击聚焦落点判定、多选整组拖拽、适应画布与缩放边界。
